# Віртуальна лабораторія «Інтегральні системи безпеки»

Онлайн-тренажер лабораторних робіт з дисципліни «Інтегральні системи безпеки» на обладнанні Hikvision.
Державний університет «Житомирська політехніка», Факультет інформаційно-комп'ютерних технологій, Кафедра комп'ютерних технологій у медицині та телекомунікаціях.

## Лабораторні роботи
1. Налаштування та дослідження IP-камери (13 кроків)
2. Камера, відеореєстратор і iVMS-4200 (12 кроків)
3. Розпізнавання облич на відеореєстраторі (9 кроків)
4. Мережеве обладнання для систем відеонагляду (8 кроків)
5. Налаштування системи IP-домофонії (8 кроків)
6. Налаштування терміналу контролю доступу (10 кроків)
7. Бездротова охоронна система AX PRO (7 кроків)

Кожна робота містить імітацію інтерфейсів пристроїв, автоматичну перевірку кроків, теорію до кожного кроку, конспект з контрольними запитаннями і генерацію звіту у форматі .docx.

## Запуск
Статичний сайт: відкрийте `index.html` або увімкніть GitHub Pages (Settings → Pages → Deploy from branch → `main` / root).

## Дані
Прогрес студента зберігається лише в його браузері (localStorage). Обличчя в ЛР 3 і ЛР 6 — синтетичні. Фото обладнання — офіційні матеріали Hikvision з viatec.ua.

## Вхід і здача
- Реєстрація лише з поштою @ztu.edu.ua після підтвердження листом (Firebase Authentication).
- Студент здає звіти лабораторних і проходить підсумковий тест (50 питань, 100 балів, ECTS) — дані у Firestore.
- Кабінет викладача (kktumtt_vvg@ztu.edu.ua): таблиця студентів по групах, звіти, оцінки й коментарі, перездача тесту, експорт CSV.
